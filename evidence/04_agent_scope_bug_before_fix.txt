## Diagnosis
The model read "Kisumu Central" as a county filter and called check_stock(county="Kisumu"),
which returned only 2 of 5 clinics. It then generalised "no reorder needed" to the whole
network. Truth (unfiltered check_stock): Vihiga Health Post (8 units) and Homa Bay Lakeside
Clinic (0 units) need a reorder. Every individual tool answer was correct; the failure was
an unstated scope in the tool contract.

## Fix (same commit series, see git log)
1. check_stock docstring: county is only for questions that explicitly ask about one county;
   a start clinic or place name is NOT a county filter.
2. check_stock result now states its scope ("clinics_included": "2 of 5 (county=Kisumu)"), so
   the model can see when it is looking at a subset.
3. System prompt: only make network-wide claims ("no clinics", "all clinics") from an
   unfiltered result.
